# Security policy

This is an early open-source baseline, not a production service. The repository does not include production credentials or the private feedback backend.

## Report a vulnerability

Please do not publish exploitable details, credentials, or personal data in a public issue. Use GitHub's **Security → Advisories → Report a vulnerability** flow for this repository. If that option is unavailable, open a minimal issue asking maintainers to provide a private reporting route; do not include the vulnerability details there.

Include the affected commit or version, impact, and steps to reproduce. Maintainers will acknowledge and coordinate a fix before public disclosure where practical. No response-time guarantee is made at this early stage.

## Scope

Report security issues in the app code, build configuration, and repository workflows. General product feedback belongs in an issue or discussion. Do not send real user records, contact details, or secrets as proof.
