# 배움 메뉴 통합 — 2026-10-22

상단 교육 콘텐츠와 배움 탭이 같은 자료를 중복 제공했다. 상단 교육 메뉴를 제거하고 배움 탭에서 오늘의 배움/전체 7일 교육을 전환하도록 통합한다.

7개 교육·21개 이미지·출처·공개 조건은 유지한다. 다른 날짜를 탐색해도 체험 날짜와 회고 초안은 유지하며, 목록/상세 이동 시 맨 위로 이동한다. 사용법 메뉴는 유지한다.
