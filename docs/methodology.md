# Simulation method

## What is modeled

The app combines a small set of self-described life conditions, fictional dog profiles, scheduled care prompts, and user-selected responses to fictional situations. The current implementation uses deterministic rules so the same saved choices produce the same summary.

## Evidence shown in the report

The report is derived from the user's recorded simulation choices and the fictional profile selected in the app. It is not an observation of a real dog, a real household, or a professional assessment. Missing and skipped activity must remain distinguishable from completed practice.

## Limits

The rule weights and profile examples have not been calibrated against adoption outcomes. They must not be described as scientifically validated, predictive, diagnostic, or proof that someone is or is not ready to adopt. A synthetic fixture checks code coverage only; it is not user research or market validation.
