# 출시 전 QA 수정 v1

- 외출 시간은 0~24 사이의 숫자를 받으며 소수를 허용한다. 필수 선택과 범위 검사를 통과해야 프로필 및 체험을 시작한다.
- 새 체험 시작 전에 시간이 끝난 첫날 요청은 `시작 전`으로 표시하며 완료·놓침·점수에서 제외한다. 시작 시 열려 있는 요청은 응답할 수 있고 이후 실제 누락은 기존대로 평가한다. 리포트는 제외 개수와 평가 대상 수를 표시한다.
- 이미 시작한 저장 기록은 소급 변경하지 않는다.
- 웹에서는 기기 알림 예약을 지원하지 않는다는 안내를 항상 표시하고 스위치를 비활성화한다. 시간 설정 저장은 유지한다.
- 기존 교육 콘텐츠 7개와 삽화21장, 사용법5장, 공개 피드백 목적지는 변경하지 않는다.
- 검증: `npm --prefix app test`, `npm --prefix app run check:public`, `npm --prefix app run build:web`. 실제 배포와 실기기 검증은 별도 단계다.
